================================================================================
                        STEP-BY-STEP

STEP 1: Open Command Prompt (CMD)

STEP 2: Navigate to your project folder
   cd C:\Users\holog\OneDrive\Desktop\EquipTrack

STEP 3: Initialize Git (if not already done)
   git init

STEP 4: Add all files
   git add .

STEP 5: Commit your code
   git commit -m "Initial commit: EquipTrack system"

STEP 6: Connect to your GitHub repo
   git remote add origin https://github.com/YOUR_USERNAME/equipment-management-system.git
   
   ⚠️ IMPORTANT: Replace YOUR_USERNAME with your actual GitHub username!

STEP 7: Set main branch
   git branch -M main

STEP 8: Push to GitHub
   git push -u origin main

   ⚠️ If prompted, enter your GitHub username and password
   (For password, use a Personal Access Token if you have 2FA enabled)

================================================================================
                        IF YOU GET ERRORS
================================================================================

ERROR: "remote origin already exists"
SOLUTION: 
   git remote remove origin
   Then run step 6 again

ERROR: "Authentication failed"
SOLUTION:
   - Use Personal Access Token instead of password
   - Generate one at: https://github.com/settings/tokens
   - Use token as password when prompted

ERROR: "not a git repository"
SOLUTION:
   Make sure you're in the right folder:
   cd C:\Users\holog\OneDrive\Desktop\EquipTrack
   Then run: git init
