=====================================
EQUIPTRACK DESKTOP APP - INSTALLATION
=====================================

STEP 1: Install Python
-----------------------
1. Download Python from: https://www.python.org/downloads/
2. Run the installer
3. ✅ IMPORTANT: Check "Add Python to PATH"
4. Click "Install Now"
5. Close and reopen PowerShell after installation

STEP 2: Install Dependencies
-----------------------------
Copy and paste these commands ONE AT A TIME in PowerShell:

cd C:\Users\holog\OneDrive\Desktop\EquipTrack\desktop-app

pip install PyQt6

pip install bcrypt

pip install python-dateutil

STEP 3: Run the Application
----------------------------
python main.py

STEP 4: Login
-------------
Email: admin@equiptrack.com
Password: admin123

=====================================
TROUBLESHOOTING
=====================================

Problem: "Python was not found"
Solution: Install Python and make sure "Add to PATH" is checked

Problem: "No module named PyQt6"
Solution: Run: pip install PyQt6

Problem: "pip is not recognized"
Solution: Python wasn't added to PATH. Reinstall Python with PATH option checked

Problem: Script execution error
Solution: Run this command first:
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
