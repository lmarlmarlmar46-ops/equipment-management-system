## ⚠️ **Troubleshooting**

### **"Invalid credentials" error?**
- Make sure you're using the exact email and password above
- Use the eye icon to verify you typed the password correctly
- Try copy-pasting the credentials

### **"Cannot connect to server" error?**
- Backend: https://equipment-management-system-production-7e9c.up.railway.app
- Check if it's running (should show "OK" status)

### **Database empty?**
- Visit: https://equipment-management-system-production-7e9c.up.railway.app/api/seed/run
- This will populate the database with demo data
