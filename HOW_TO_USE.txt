================================================================================
                          TROUBLESHOOTING
================================================================================

PROBLEM: Can't push to GitHub
SOLUTION:
   1. Check you're in right folder: cd C:\Users\holog\OneDrive\Desktop\EquipTrack
   2. Check Git is initialized: git status
   3. Check remote is set: git remote -v

PROBLEM: Railway deploy fails
SOLUTION:
   1. Go to Railway dashboard
   2. Click on service that failed
   3. Click "Deployments" tab
   4. Click latest deployment
   5. Read error logs
   6. Usually: check environment variables or Root Directory setting

PROBLEM: Website shows error
SOLUTION:
   1. Press F12 in browser
   2. Check Console for errors
   3. Check Railway logs for backend errors
   4. Verify environment variables are correct

PROBLEM: Can't login
SOLUTION:
   1. Check backend is running (green in Railway)
   2. Verify database was initialized (ran init.sql)
   3. Check FRONTEND_URL in backend matches frontend URL
   4. Check VITE_API_URL in frontend matches backend URL
